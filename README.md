## Emmet

Emmet är ett vektyg för att smidigare skriva kod. För att skapa en tabell i html skulle man skriva ut manuellt:

```
<table>
    <tr>
        <th></th>
        <th></th>
    </tr>
    <tr>
        <th></th>
        <th></th>
    </tr>
</table>
```

för att skapa en 2x2 tabell. Med hjälp av Emmet skriver man istället:

 ```table>tr*2>th*2``` 
 
 och får samma resultat men med mycket färre tecken.

Även delar som att slippa skriva ut ```<>``` runt delar som ```head``` snabbar på kodskrivandet
